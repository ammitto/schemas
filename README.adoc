= Ammitto Schemas

Canonical JSON Schema definitions for the Ammitto sanctions data model.

== Overview

This repository holds the versioned schema documents that describe the
harmonized JSON-LD representation used across all `ammitto/data-*`
repositories. Consumers (the `ammitto` gem, the website, and downstream
integrations) reference these schemas to validate entity, entry, and
ontology documents.
