= Ammitto Schemas

Schema repository status and links to the Ammitto validation contracts.

== Overview

This repository currently contains documentation only. It does not publish
schema files, and the gem and website do not load validation contracts from
this repository.

The executable validation contracts are maintained and packaged with
link:https://github.com/ammitto/ammitto/tree/main/schemas[the ammitto gem].
Its China and Japan input schemas describe the curated YAML records consumed
by their source loaders. Input schemas and harmonized JSON-LD output contracts
describe different representations; use the contract for the data being
validated.

Changes to executable contracts belong in the gem repository alongside the
validator, regression tests, and exporters that use them. Keeping those changes
together allows consumers to pin a gem version and its matching schemas.
